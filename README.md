# MET-Based Activity Calorie Burn Planner

Estimate calories burned using MET (Metabolic Equivalent of Task) values for 100+ activities based on body weight and duration, with session logging and history chart.

## Features
- 100+ activities across 12 categories: Walking, Running, Cycling, Swimming, Yoga, Strength, Sports, Cardio, Martial Arts, Outdoor, Everyday, Dance
- MET-based formula: kcal = MET × weight(kg) × hours
- Search and category filter for activities
- Body weight input (kg or lbs)
- Per-activity add modal with duration input and live calorie preview
- Daily goal ring with progress indicator
- Session log with remove functionality
- Session save to history with bar chart
- localStorage persistence for history

## Usage
Set your body weight and daily calorie goal. Search or filter activities, click + to add with duration. The session log shows total calories toward your goal. Save sessions to see history chart.

## Tech
- Tailwind CSS CDN
- Chart.js CDN
- Vanilla JS
- localStorage
